Original M4A recordings remain untouched in the parent folder. File mapping is in file_mapping.csv.
The numbered passages match the supplied script by speech-to-text content. Emotion labels identify the requested performance, not an automatic judgement of how convincing the acting is.
Copies are mono PCM16 WAV at the original sample rate, with constant gain to -3 dBFS peak. This preserves timing and pitch; it does not remove noise or repair distortion already in the recording.
