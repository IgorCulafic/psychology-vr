# Text conversation testing

Run `./tools/launch-text-chat.ps1` from the project folder, then open http://127.0.0.1:8794/. This starts/reuses the configured local Qwen server and opens a browser. No headset, Unity, speech recognition or voice model is needed. The saved VR configuration is unchanged; the text service overrides speech providers only in memory.

Choose Alex, Nikola, Stefan or Ivan. Type as the student/psychologist and press Enter (Shift+Enter adds a line). Choose Montenegrin or English. Switching character/language or clicking **New conversation** clears the visible conversation and creates a new session. Case descriptions are hidden initially; **Show case descriptions** reveals the instructor-facing summary. This is a local development tool, not an access-controlled student exam.

**Show emotional cues** reveals the final emotion, intensity, gesture, gaze and voice style sent to playback. It does not demonstrate rendered animation or voice quality. Text and emotional output use the same `Bridge.turn`, prompt builder, profile files, response validation, generation settings and bounded history as VR. The visible transcript can be longer than the model's retained context: up to four preceding turns are sent to Qwen, with fewer if needed to reserve room for a complete reply. Relationship state persists separately from that dialogue window. Relevant attributed excerpts from up to 96 completed exchanges now provide additional bounded recall; exports include retrieved and actually included memory excerpts. See [memory design and limits](CONVERSATION_MEMORY.md).

**Stop reply** discards an in-flight response. A request already computing in llama.cpp may still need to finish before another can run. Sessions are saved automatically to `logs/sessions/`, with a readable transcript and structured JSONL events after each accepted turn. Resetting or switching characters preserves earlier logs. See [automatic logging](SESSION_LOGGING.md) for contents and limits. **Export transcript** additionally downloads a browser JSON transcript with messages, cues, timings and failed/interrupted turn markers. Reloading the page starts a fresh session; server restarts clear live context but preserve saved logs. At 32 open sessions per language, restart the text service.

Useful tests: begin with an open question; ask a focused follow-up; gently offer an inaccurate assumption and see whether the patient corrects it; offer reassurance without expecting an instant cure. Look for short relevant replies, gradual disclosure, consistent facts, natural disagreement and no therapist-like diagnosis or treatment lecture. Export examples that fail, including the preceding turns.

Alex, Nikola, Stefan and Ivan now show **Comfort with you**, which persists alongside trust, distress and remembered boundaries. Comfort primarily regulates sensitive disclosure; ordinary conversation and requests to elaborate do not require high trust. Repeated mistreatment can end a session and disable input until **New conversation**. Emotional cues expose additional state; exports include the state and inferred topic after each turn. These are simulation controls, not clinical scores. See [relationship behaviour and limits](PATIENT_RELATIONSHIPS.md).

Stop all project services with `./tools/stop-services.ps1`. To close only the text server while keeping VR/model services, use `./tools/stop-services.ps1 -TextOnly`. Closing the browser alone does not unload Qwen. The server binds only to this PC's loopback address, validates same-origin browser requests, and does not change the VR bridge's browser-access restrictions.
